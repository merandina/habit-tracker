# Habit Tracker

A simple, interactive habit tracker built with HTML, CSS, and JavaScript. Track daily habits, organize them by category, and monitor your progress through a clean, dark-themed interface.

## Live Demo

Try the Habit Tracker : (https://merandina.github.io/habit-tracker/)

## Features

- Add new habits and assign categories
- Edit habit names
- Delete habits
- Mark habits as completed
- Track completion progress with a percentage and progress bar
- Save habits and their completion status using browser local storage

## Technologies Used

- **HTML5** — page structure
- **CSS3** — styling and layout
- **JavaScript** — functionality and DOM manipulation
- **localStorage** — persistence of habits in the browser

## How to Run Locally

1. Clone or download this repository.
2. Open `index.html` in your browser.
3. Start adding and tracking your habits.
